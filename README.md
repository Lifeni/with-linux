# With Linux

面向 arm64 / amd64 Linux 的轻量 TUI 控制面板，通过 SSH 按需启动，命令名为 `wl`。

</p>

> 本项目由 AI 协作完成：代码、文档与迭代均经 AI 生成和优化。

## 功能

- 实时查看 CPU、内存、磁盘、网络、温度和系统负载。
- 查看并控制本机 Docker 容器，浏览最近日志。
- 查看 Caddy 路由、上游状态和配置文件，并执行热重载。
- 在面板内查看 OpenCode Go 与 Command Code 的用量。
- 支持鼠标、键盘、窄终端和单文件部署。
